# Wortarten

**Wortarten-Detektiv** – ein Lernspiel für die Grundschule: Die Kinder ordnen Wörter den Wortarten zu.

- 🔴 **Nomen** (Namenwort)
- 🔵 **Verb** (Tunwort)
- 🟢 **Adjektiv** (Wiewort)

## Funktionen
- Wortpool mit 329 einfachen Wörtern (140 Nomen, 95 Verben, 94 Adjektive)
- Runden mit 10, 20, 30 oder 50 Wörtern
- Wahlweise alle Wörter in GROSSBUCHSTABEN, damit die Großschreibung das Nomen nicht verrät
- Tipps bei Fehlern, Punkte, Serien-Bonus und Sterne
- „Fehler üben“ am Ende der Runde

## Spielen
Einfach `index.html` im Browser öffnen – funktioniert ohne Internet, auch auf Tablet und Smartphone.
